VALOREN VERO — starter store

WHAT'S INCLUDED
- Responsive black/purple storefront
- Product categories and sample products
- Product detail modal with size/color selection
- Shopping bag and WhatsApp order draft
- No payment processing and no Migvan integration yet

BEFORE LAUNCH
1. Open script.js.
2. Replace WHATSAPP_NUMBER with your number in international format, digits only.
   Example for an Israeli number: 9725XXXXXXXX (without +, spaces or leading 0).
3. Replace the sample products in the `products` array with your real product names and prices.
4. Add real product photos. The current VV product tiles are graphic placeholders, not product photos.
5. Confirm prices, sizes, stock, shipping and return terms before accepting orders.

GITHUB PAGES
1. Create a GitHub repository named `valoren-vero-store`.
2. Upload index.html, style.css, script.js and the assets folder.
3. In repository Settings > Pages, select Deploy from a branch, choose main and /(root).
4. Save and wait for GitHub Pages to publish.

IMPORTANT
This is a static catalog and WhatsApp order-request prototype. It does not collect card payments,
confirm stock, calculate shipping, or send orders to Migvan4u automatically.
Do not publish until you replace all placeholders and test the order flow.
